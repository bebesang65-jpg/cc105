📚 Encryption Information

Cipher Used: AES-256-GCM

AES: Advanced Encryption Standard

Key Size: 256-bit

Mode: Galois/Counter Mode (GCM)

This website allows users to enter a message, encrypt it using AES-256-GCM, and publish the encrypted message in a public feed.

🔑 A unique secret key is generated for every message. The secret key is required to decrypt the message.
